# Github Explorer

An iOS app for exploring GitHub repositories, built with Swift and UIKit.

## Requirements

- iOS 13.0+
- Xcode 13+
- Swift 5

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/savalex93/Github-Explorer.git
   ```
2. Open `Github Explorer.xcodeproj` in Xcode.
3. Build and run on a simulator or device.
